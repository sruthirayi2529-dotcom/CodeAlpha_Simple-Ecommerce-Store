# CodeAlpha Simple Ecommerce Store

A simple full-stack e-commerce store built with Node.js, Express and JavaScript.

**Intern:** Sruthi Rayi
**Internship:** CodeAlpha - Web Development
**Task 1:** Simple Ecommerce Store

### Features
- Product listing page
- Product details page  
- Add to cart functionality
- Cart page with total calculation
- Responsive design

### Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Storage: LocalStorage for cart

### How to Run
1. Clone the repo
2. Run `npm install`
3. Run `node server.js`
4. Open http://localhost:3000
